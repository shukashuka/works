How to use this folder:

1. Create one subfolder per project. The subfolder's name becomes
   the project title shown on the site (e.g. "Coffee Shop Branding",
   "Concert Poster Series").
2. Put all of that project's photos inside the subfolder
   (jpg/png/webp/gif).
3. Commit & push to GitHub. The site automatically reads this
   folder through the GitHub API — no code changes needed.
4. Your repo must be PUBLIC for the GitHub API to work without
   logging in (see README.md in the project root).

3 example folders (project-a, project-b, project-c) are included
as placeholders — rename them to your real project names and
replace their contents with your actual photos.
